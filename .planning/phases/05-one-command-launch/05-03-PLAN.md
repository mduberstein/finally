**Image contract from Plan 01:** the app image builds from the repository root, exposes 8000, runs uvicorn as non-root user `finally`, and sets `FINALLY_DB_PATH=/app/db/finally.db`, `FINALLY_STATIC_DIR=/app/static`. The `/app/db` directory exists in the image and is owned by `finally`, so with no volume mounted there the container writes its SQLite file into its own ephemeral writable layer — which is exactly the isolation D-03 asks for, achieved by declaring no volume at all rather than by pointing one somewhere else.

**Runtime base has no curl.** The runtime stage is `python:3.12-slim`. A compose healthcheck must use the image's own Python (`/app/.venv/bin/python` is first on PATH) rather than curl or wget.

**Mock LLM gate:** `backend/app/chat/llm.py` `call_llm()` returns `mock_response(messages).model_dump_json()` and never touches LiteLLM when `os.getenv("LLM_MOCK", "").strip().lower() == "true"`. The comparison is on the exact lowercased string `true`, so the compose value must be the string `true` — quote it in YAML so it is not coerced to a boolean and rendered as `True`.

**Mock behaviors that Plan 04's specs will rely on** (`backend/app/chat/llm.py` `mock_response`):
- A message matching buy-or-sell, whitespace, a digit run, optional "shares of", then a ticker, returns a `message` of the form `Mock: buy 2 AAPL.` and one trade action.
- A message containing "add", a ticker, and later "watchlist" returns `Mock: added PYPL to the watchlist.` and one add action.
- A message containing "remove", a ticker, and later "watchlist" returns the remove equivalent.
- Anything else returns `Mock response: portfolio and watchlist unchanged.` with both arrays empty.
Executed trade actions carry `type` of `trade`, `status` of `executed`, plus `ticker`, `side`, `quantity`, and `price` (`backend/app/chat/service.py` lines 127-132).

**Frontend selectors that exist today.** There are no `data-testid` attributes anywhere in `frontend/`. Do not add any — the accessible and text locators below are sufficient and are the locator style Playwright recommends:
- Watchlist panel: a `section` whose `h2` is `Watchlist`
- One watchlist row: a `div` with `role="button"` containing a nested `button` with an `aria-label` of the exact form `Remove AAPL from watchlist` — this aria-label is the reliable per-ticker handle, including for the single-letter ticker `V`
- Add-to-watchlist input: `#watchlist-add-ticker`, placeholder `Ticker`; its submit control is a button labelled `Add`
- Trade panel: `#trade-ticker` (placeholder `AAPL`), `#trade-quantity` (placeholder `10`), buttons labelled `Buy` and `Sell`
- Positions panel: a `section` whose `h2` is `Positions`; the empty state renders the heading text `No open positions`
- Header: the literal labels `Cash` and `Total Value`, each followed by a formatted number
- Connection indicator: an element with `role="status"` whose text is exactly one of `Connected`, `Reconnecting`, `Disconnected`
- Chat panel: an input with placeholder `Ask about your portfolio, or tell me to trade...` and a button labelled `Send`
- Price flash: a changed price cell briefly carries the class `animate-flash-up` or `animate-flash-down`

**Number formatting.** `frontend/lib/format.ts` `formatPrice` returns a grouped two-decimal string with NO currency symbol. A fresh ten-thousand-dollar balance renders as the text `10,000.00`. Do not assert a dollar sign in header or table figures.

**Fresh-database seed** (`backend/app/db/database.py`): cash `10000.0`, watchlist in this exact order: AAPL, GOOGL, MSFT, AMZN, TSLA, NVDA, META, JPM, V, NFLX. No positions, no trades, no chat messages.

**Streaming cadence:** the simulator ticks roughly every 500ms; the SSE stream pushes changes at the same cadence with a 15-second heartbeat. `frontend/lib/connection.ts` marks the indicator `Connected` on the EventSource open event or on any message.

**Playwright version pin:** `@playwright/test` 1.62.1, and the matching official image `mcr.microsoft.com/playwright:v1.62.1-noble`. The npm package and the image tag must stay in lockstep — a mismatch means the pre-installed browsers do not match the runner.

**Package legitimacy:** `@playwright/test` was audited in RESEARCH.md and approved. The automated legitimacy seam returned SUS purely because its live-signal fetch returned null for age, downloads, and repository in that session; direct npm-registry queries confirmed creation 2020-09-24, roughly 37.5M weekly downloads, the official `github.com/microsoft/playwright` repository, and no postinstall script. No human legitimacy checkpoint is required. Install with `npm ci` against a committed lockfile.

**Environment note for the executor:** the agent Bash sandbox denies the Docker daemon socket. Every `docker` and `docker compose` invocation must run with `dangerouslyDisableSandbox: true`.
