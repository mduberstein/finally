## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host network → published container port | Determines who on the network can reach the unauthenticated API |
| shell script → host `db/` directory | The scripts run with the invoking user's full filesystem rights next to the user's live portfolio data |
| `.env.example` → `.env` seeding | An automated file write into the location that holds the real credential |
| repository documentation → operator behavior | A README that documents a destructive step wrongly is itself a data-loss vector |
