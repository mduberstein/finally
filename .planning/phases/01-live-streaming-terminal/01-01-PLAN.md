## Phase Goal

**As a** visitor opening FinAlly for the first time, **I want to** see ten default tickers streaming live prices in a dark trading terminal, **so that** I can watch the market move without reloading the page.

<objective>
Stand up the walking skeleton: a real SQLite database that seeds itself, a FastAPI app that starts the already-built MarketFeed and serves both the SSE stream and the Next.js static export, and a browser page that shows the ten seeded tickers with prices that visibly change.

Purpose: every later phase (trading, portfolio visuals, AI copilot) hangs off this host. Proving the whole stack end-to-end now means a wrong architectural turn costs one commit instead of ten.
Output: `backend/app/db/`, `backend/app/main.py`, the `frontend/` project, and a documented command that runs the full stack locally.
</objective>

Create `database.py` exporting `DEFAULT_USER_ID = "default"`, `DEFAULT_TICKERS` as a tuple in exactly this order — AAPL, GOOGL, MSFT, AMZN, TSLA, NVDA, META, JPM, V, NFLX — plus:

- `connect() -> sqlite3.Connection` — opens a new short-lived connection with `row_factory = sqlite3.Row` and foreign keys enabled. A fresh connection per call keeps this free of cross-task state; local SQLite reads are microseconds, and the feed's 2 Hz poll is not a load concern.
