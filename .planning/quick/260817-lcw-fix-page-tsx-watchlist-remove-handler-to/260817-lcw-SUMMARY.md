# Quick Task 260817-lcw: Fix watchlist remove handler to clear selectedTicker (WR-03) Summary

Added a pure `clearSelectionIfRemoved` helper and wired it into `handleRemove` so removing the currently-selected ticker clears `MainChart`'s stale frozen-price header instead of leaving it displayed forever.

## What Was Built

- **`frontend/lib/selection.ts`** — a single pure function `clearSelectionIfRemoved(current: string | null, removed: string): string | null`. Returns `null` when the removed ticker matches the current selection, otherwise returns `current` unchanged (identical reference, so React's state bail-out prevents a redundant re-render on unrelated removals).
- **`frontend/lib/selection.test.ts`** — 4 unit tests covering: clearing on match (the WR-03 case), preserving on an unrelated removal, no-op when nothing is selected, and reference-identity preservation.
- **`frontend/app/page.tsx`** — `handleRemove`'s `body.removed` branch now calls `setSelectedTicker((current) => clearSelectionIfRemoved(current, ticker))` immediately after the existing `setWatchlist` call, using the functional updater form to avoid reading a stale-closure `selectedTicker`.
